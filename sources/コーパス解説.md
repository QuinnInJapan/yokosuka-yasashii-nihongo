## やさしい日本語の基準について

やさしい日本語の「やさしさ」の定義は統一されておらず、コーパスごとに異なる基準が使われています。主な基準は以下の3種類です。

### 1. 旧日本語能力試験（旧JLPT）3級・4級準拠

弘前大学の佐藤和之教授が1995年の阪神・淡路大震災を契機に提唱した方式です。旧日本語能力試験の3級・4級（現在のN4・N5相当）の語彙・文法リストを基準とします。

- **利点**: 日本語教育で広く知られた基準であり、学習者・教師がレベル感を共有しやすい
- **欠点**: 2010年以降の新JLPTでは公式語彙リストが非公開となり、旧リストは2009年時点で凍結されている。実際の使用頻度と一致しない語彙も含まれる

出入国在留管理庁・文化庁の「在留支援のためのやさしい日本語ガイドライン」（2020年）もこの系統に属しますが、具体的な語彙リストは指定していません。

### 2. 独自語彙リスト方式（SNOW方式）

長岡技術科学大学の山本研究室が定義した、UniDic短単位に基づく約2,000語の独自リストです。

- **利点**: 網羅性（できるだけ多くの文の意味を保持できるよう選定）と冗長性排除（同義語は簡単な方を採用）を考慮
- **欠点**: JLPT等の外部基準と対応しないため、「やさしさ」のレベル感が他の資源と比較しにくい。リストは丸山拓海氏の修士論文（2020年）の付録に掲載

### 3. JLPT N4準拠（MATCHA方式）

株式会社MATCHAが訪日外国人向け記事で採用している方式で、JLPT N4相当の語彙・文法に制限します。

- **利点**: 現行の能力試験レベルに準拠しており、「日本語学習歴約6ヶ月の読者」という明確な対象像がある
- **欠点**: N4の公式語彙リストは非公開であり、実際にはMATCHA編集部の判断に依存している部分がある

### 政府の公式基準

日本政府が定めたやさしい日本語の統一語彙リストは**存在しません**。事実上の標準は旧JLPT 3級・4級の語彙リストであり、弘前大学ガイドラインの「はさみの法則」（はっきり言う・さいごまで言う・みじかく言う）が広く参照されています。

## 収録済みコーパス

### MATCHA（愛媛大学）

| 項目 | 内容 |
|------|------|
| **規模** | 約14,700文対（同一文対を除外後） |
| **種別** | 文レベル |
| **語彙基準** | JLPT N4相当 |
| **文法制限** | あり（N4文法に制限） |
| **作成者** | 株式会社MATCHAの専門ライター |
| **原文の分野** | 旅行・文化（訪日観光情報記事） |
| **ライセンス** | 要確認（学術論文に基づく） |
| **所在** | `sources/matcha_repo/` |

#### 長所
- **専門家が実用目的で作成した唯一のコーパス**: 研究用ではなく実際の読者向けに書かれたやさしい日本語であり、平易化の操作が多様（語彙置換だけでなく、文の分割・削除・再構成を含む）
- **JLPT N4準拠**: 広く理解されている能力試験レベルに対応
- **品質が高い**: 人手評価で「流暢かつ適切に平易化されている」と確認済み

#### 短所
- **分野が旅行・文化に偏る**: 行政文書や防災情報とは語彙・文体が異なる
- **原文が比較的平易**: 元の記事がジャーナリスティックな文体であり、硬い行政用語の平易化例は少ない

#### 参考文献
- 宮田りな他 (2024)「MATCHA：専門家が平易化した記事を用いたやさしい日本語パラレルコーパス」『自然言語処理』31(2). [J-STAGE](https://www.jstage.jst.go.jp/article/jnlp/31/2/31_590/_article/-char/ja/)

### SNOW T15（長岡技術科学大学）

| 項目 | 内容 |
|------|------|
| **規模** | 50,000文対 |
| **種別** | 文レベル |
| **語彙基準** | 独自2,000語リスト（UniDic短単位） |
| **文法制限** | なし（語彙のみ制限） |
| **作成者** | 大学院生5名 |
| **原文の分野** | 田中コーパス（汎用例文集） |
| **ライセンス** | CC BY 4.0（再配布可） |
| **所在** | `sources/snow_t15/` |

#### 長所
- **最大規模**: 自由に利用できるやさしい日本語コーパスとして最大（50,000文対）
- **CC BY 4.0**: 公開アプリや再配布が可能
- **英語対訳付き**: 原文の英語訳も含まれており、3言語並行データとして利用可能

#### 短所
- **非専門家による平易化**: 大学院生が作成しており、やさしい日本語の専門家ではない
- **ノイズが多い**: Kajiwara et al. (2022) がフィルタリングの必要性を指摘しており、冗長な言い換えや不自然な文対が含まれる
- **独自語彙基準**: 2,000語リストはJLPT等の外部基準と対応しないため、「やさしさ」のレベルが不明確
- **原文の分野が不自然**: 田中コーパス（例文集）が元データであり、自然な文章ではなく構成された例文が多い
- **文法の平易化がない**: 語彙の置換のみで、複雑な文構造（受身・使役・敬語等）はそのまま残る場合がある

#### 参考文献
- Maruyama & Yamamoto (2018) "Simplified Corpus with Core Vocabulary." LREC 2018. [ACL Anthology](https://aclanthology.org/L18-1185/)

### SNOW T23（長岡技術科学大学）

| 項目 | 内容 |
|------|------|
| **規模** | 34,300文対 |
| **種別** | 文レベル |
| **語彙基準** | 独自2,000語リスト（T15と同一） |
| **文法制限** | なし |
| **作成者** | クラウドワーカー7名 |
| **原文の分野** | 田中コーパス（T15と重複なし） |
| **ライセンス** | CC BY 4.0（再配布可） |
| **所在** | `sources/snow_t23/` |

#### 長所
- **大規模**: T15と合わせて84,300文対が利用可能
- **CC BY 4.0**: 公開アプリや再配布が可能
- **アノテーター間一致度の検証あり**: 100文を全7名が共通で平易化しており、作業者間のばらつきを確認できる

#### 短所
- **クラウドワーカーの品質のばらつき**: 言語学の訓練を受けていないワーカーが作成しており、T15の大学院生よりも品質が不安定な可能性がある
- **T15と同じ短所を共有**: 独自語彙基準、文法制限なし、ノイズあり、原文が例文集
- **固有名詞の判断が作業者依存**: 固有名詞をどう扱うかが個人の判断に委ねられている

#### 参考文献
- Katsuta & Yamamoto (2018) "Crowdsourced Corpus of Sentence Simplification with Core Vocabulary." LREC 2018. [ACL Anthology](https://aclanthology.org/L18-1072/)

### JADES（奈良先端科学技術大学院大学）

| 項目 | 内容 |
|------|------|
| **規模** | 3,907文対（train 2,959 / valid 448 / test 500） |
| **種別** | 文レベル |
| **語彙基準** | 旧JLPT 3級・4級相当（公的語彙・文法プロファイル準拠） |
| **文法制限** | あり（文法プロファイルに準拠） |
| **作成者** | 専門家1名 |
| **原文の分野** | ニュース記事（英語ニュースの和訳） |
| **ライセンス** | 要確認（GitHub公開） |
| **所在** | `sources/jades/` |

#### 長所
- **旧JLPT準拠**: やさしい日本語の事実上の標準であるJLPT 3級・4級に準拠しており、他の行政資料と基準が一致する
- **文法の平易化を含む**: SNOWと異なり、語彙だけでなく文法構造の平易化も行われている
- **多様な平易化操作**: 置換・削除・分割・書き換えなど幅広い操作が含まれる
- **品質評価データ付き**: 複数のシステム出力に対する人手評価スコア（流暢性・意味保存性・平易性）も提供

#### 短所
- **規模が小さい**: 3,907文対のみで、大規模な学習データとしては不十分
- **単一アノテーター**: 専門家1名のみが作成しており、個人の癖が反映されている可能性がある（アノテーター間一致度の検証不可）
- **翻訳調の原文**: 英語ニュースの和訳が元データであるため、翻訳体（translationese）の影響がある可能性
- **評価用途が主目的**: 訓練データではなく評価データとして設計されている

#### 参考文献
- Hayakawa et al. (2022) "JADES: New Text Simplification Dataset in Japanese Targeted at Non-Native Speakers." TSAR-2022. [ACL Anthology](https://aclanthology.org/2022.tsar-1.17/)

### 行政・自治体ガイドライン

| 項目 | 内容 |
|------|------|
| **規模** | 約3,000語句対（15出典の合計） |
| **種別** | 語句レベル（用語→やさしい日本語） |
| **語彙基準** | 旧JLPT 3級・4級相当（弘前大学方式） |
| **作成者** | 各自治体・省庁の職員・専門家 |
| **原文の分野** | 行政用語・防災・医療・雇用 |
| **ライセンス** | 公的機関の公開資料（多くは自由利用可能） |
| **所在** | `data/01_*.json` ～ `data/22_*.json` |

出典一覧: 出入国在留管理庁・文化庁、弘前大学、鳥取県、川崎市、札幌市、福岡市、三重県、大阪市、横浜市、大阪府、愛知県、岡山県、京都市、入間市、CLAIR、厚生労働省

#### 長所
- **実務で使われている公式の書き換え例**: 自治体の窓口・広報で実際に使われている語句集であり、行政文書の平易化において最も権威がある
- **分野の多様性**: 行政手続き、防災、医療、雇用など幅広い分野をカバー
- **複数出典の合意が確認できる**: 同じ語句が複数の自治体で同様に書き換えられている場合、その書き換えの信頼性が高い
- **弘前大学方式（旧JLPT準拠）が主流**: やさしい日本語の事実上の標準に沿っている

#### 短所
- **規模が小さい**: 各出典は数十～数百語句程度であり、合計でも約3,000語句対
- **語句レベルのみ**: 文レベルの平易化例は少なく（岡山県・CLAIRのみ）、文脈に応じた使い分けの情報が乏しい
- **形式が統一されていない**: 出典ごとにPDF、Excel、Webページなど形式が異なり、抽出の手間がかかる

## 語彙基準の比較

| 基準 | 語彙数 | 定義元 | 利点 | 欠点 |
|------|--------|--------|------|------|
| 旧JLPT 3級・4級 | 約1,500語 | 国際交流基金（2009年以前） | 広く知られた基準。やさしい日本語の事実上の標準 | 2010年以降更新なし。低頻度語を含む |
| SNOW独自2,000語 | 2,000語 | 長岡技術科学大学 | 網羅性と簡潔性を考慮 | 外部基準と非対応。比較しにくい |
| JLPT N4 | 非公開 | 国際交流基金（現行） | 現行試験に対応 | 公式リスト非公開。実質的に運用者の判断 |
| 日本語教育語彙表（JEV） | 17,920語 | 筑波大学（砂川有里子 他） | 6段階の難易度・旧JLPTタグ・BCCWJ頻度を統合 | 大規模すぎて「やさしい」の閾値が不明確 |
